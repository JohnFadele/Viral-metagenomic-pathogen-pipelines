Description of Phylogenetic visualisation and comparative clustering workflows

This pipeline provides a reproducible workflow for phylogenetic visualisation, metadata integration, and hierarchical clustering analysis of pathogen sequence datasets. It supports transformation of phylogenetic inference outputs into publication-ready visual representations that integrate evolutionary relationships with epidemiological metadata.

The workflow includes metadata validation against phylogenetic tree membership, construction of annotated phylogenetic trees with country and host level visual encoding, extraction of tree-specific metadata, and hierarchical clustering of genetic distance matrices for comparative cluster analysis. Heatmap generation incorporates epidemiological annotations and cluster labelling to support interpretation of evolutionary structure, geographic relatedness, and host-associated clustering patterns.

Overall, this workflow provides a structured framework for phylogenetic interpretation, metadata-driven visual analytics, and comparative evolutionary exploration.
